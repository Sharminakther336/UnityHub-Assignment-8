# UnityHub – Social Development Events Platform

UnityHub is a community-driven platform where users can create, explore and join social development events.

## Features
- User Registration and Login
- Google Authentication
- Browse Upcoming Events
- View Event Details
- Create and Join Events
- User Dashboard
- About and Contact Pages

## Technologies Used
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Better Auth
- Google OAuth

## Concepts Used
- Next.js App Router
- React Components
- REST API
- CRUD Operations
- Fetch API
- Async/Await
- TypeScript
- Responsive Design
- Authentication
- Git and GitHub

## Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
